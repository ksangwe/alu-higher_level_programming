# JavaScript - Web jQuery

Front-end web development project using jQuery for DOM manipulation and AJAX requests.

## Tasks

* `0-script.js` - Update header color to red using `document.querySelector`
* `1-script.js` - Update header color to red using jQuery
* `2-script.js` - Turn header red on click of `DIV#red_header`
* `3-script.js` - Add `red` class to header on click
* `4-script.js` - Toggle header class between `red` and `green`
* `5-script.js` - Add `<li>Item</li>` to `UL.my_list` on click
* `6-script.js` - Update header text to `New Header!!!` on click
* `7-script.js` - Fetch and display a Star Wars character name
* `8-script.js` - Fetch and list all Star Wars movie titles
* `9-script.js` - Fetch and display "hello" translation in `DIV#hello`
