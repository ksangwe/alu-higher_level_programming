# JavaScript - Web scraping

This directory contains scripts for reading files, manipulating JSON data,
and using the `request` module to fetch and scrape data from APIs.

## Files

| File | Description |
| --- | --- |
| `0-readme.js` | Reads and prints the content of a file in utf-8. |
| `1-writeme.js` | Writes a string to a file in utf-8. |
| `2-statuscode.js` | Displays the status code of a GET request using the `request` module. |
| `3-starwars_title.js` | Prints the title of a Star Wars movie by its ID using the Star Wars API. |
| `4-starwars_count.js` | Prints the number of movies featuring Wedge Antilles (character ID 18). |
| `5-request_store.js` | Gets the contents of a webpage and stores it in a file in utf-8. |
| `6-completed_tasks.js` | Computes the number of completed tasks by user ID from an API. |
